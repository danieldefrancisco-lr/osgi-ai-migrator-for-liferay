# OSGi AI Migrator for Liferay

To migrate a legacy Liferay OSGi module to Liferay Objects and Client Extensions, follow the instructions in
[SKILL.md](SKILL.md) in this folder: analyze with the bundled CLI, plan, generate from the playbooks in
`references/knowledge/`, and run `verify` until it is clean. The CLI needs Java 17 or later.
